## 2. The takeaway

**Proposed heading (8 words):** "A schema guarantees the form, not the values"

**Short answer:** Give Claude a JSON schema, as a tool that `tool_choice` makes Claude call, and the output always parses. Code must still check the values, and a field that a source can lack must be nullable, so that Claude does not invent a value.

Support: F1 to F3, F6 (form), F7 to F9 (`tool_choice`), F12 and GUIDE 474 (values), GUIDE 482 and F15 (nullable). Condition: the newest models reject a forced `tool_choice` (F10, C2).

## 9. Conflicts

- **C1. "Tool use" as the guarantee.** K1 (GUIDE 472) gives the guarantee to tool use. The documentation gives it only with `strict: true` (ST 7, 18) or structured outputs (SO 54), and then "in most cases" (SO 2708). The exam uses the guide.
- **C2. Forced `tool_choice` on current models.** S2 and S3 (GUIDE 480, 481) teach `any` and a forced tool. These fail on four current models (DT 564) and with manual extended thinking (DT 563). The mock builder follows the documentation (decision 0040). The exam uses the guide.
- **C3. Semantic errors.** No documentation sentence states K3 (GUIDE 474). SO 58 and SO 2636 support it only in part. The claim rests on the guide.
- **C4. S5 and S6.** No page read names an "other" + detail field, an "unclear" value, or normalization rules in the prompt. The claims rest on the guide.
- **C5. Optional fields.** S4 (GUIDE 482) asks for nullable fields. SO 2772 says "Make parameters `required` where possible." A required field of type `["string", "null"]` satisfies both, within the limit of 16 (SO 2754). The exam uses the guide.
- **C6. Mock builder records.** Decision 0040 line 6 says that the diagrams of steps 2, 4 and 6 show the deviation. Diagram 08 (step 6) and diagram 07 (step 5) have no text "structured outputs" or "4.3". Diagram 06 (step 4) lists S5, but not K1 and S3 of its build guide. Build guide step 2 line 45 says "The current models accept only "auto" and "none"", but DT 563 names Claude Opus 5 and Claude Haiku 5.5 as models that accept a forced call.
- **C7. The page changed after decision 0040.** Decision 0040 line 53 quotes DT7: "(Claude Opus 5 supports it with thinking on)". DT 563 now adds that "a forced call skips thinking". The decision stays correct. SO has one line more than SO7 (SO 26), so the card `s3-docs` (SO7 line 2637) is SO 2638.
