## 2. The takeaway

**Proposed heading (8 words):** "Each claim keeps its source, date and conflicts"

**Short answer:** Each subagent returns its findings as structured records: the claim, the excerpt, the source and the date. The synthesis keeps these records, shows both values when credible sources disagree, and separates settled findings from contested ones.

## 5. Beyond the exam

1. **API citations and structured outputs do not mix.** CIT 388: "If you enable citations on any user-provided document (`document` blocks or `search_result` blocks) and also include the `output_config.format` parameter (or the deprecated `output_format` parameter), the API returns a 400 error." Condition: Claude API. Marked: the guide asks for claim-source mappings "in structured outputs" (K4, S4). In one request, you choose the built-in citations or a JSON schema, not both (C2).
2. **A scanned PDF gives no citations.** CIT 996: "As image citations are not yet supported, PDFs that are scans of documents and do not contain extractable text are not citable." Condition: Claude API citations.
3. **The size of a block sets the size of a citation.** SR 1253: "The text block is the minimal citable unit: Claude cites whole blocks, not substrings within a block." Condition: `search_result` blocks. CIT 378 adds a cost fact: "The `cited_text` field is provided for convenience and does not count toward output tokens." For short excerpts (S1), use small blocks.

```json
    // Required: Array of text blocks

      "type": "text",

  ],
  "citations": {
    // Optional: Citation configuration

```
