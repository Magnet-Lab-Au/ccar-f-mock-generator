## 2. The takeaway

**Proposed heading (10 words):** "Grep finds content, Glob finds files, Edit needs unique text"

**Short answer:** Search first: Glob finds files by name, Grep finds text inside files, and Read then follows only the files that matter. Edit changes a part of a file and needs text that occurs once, and if the text is not unique, the guide uses Read and then Write of the whole file.

Support: F1 to F3 (Grep), F4 to F6 (Glob), F7 to F9 (Read, Write, Edit), F10 to F12 (the unique match and its fallback, C2), F13 to F15 (search first, read less). The platform condition is in F16 and C1.

## 5. Beyond the exam

1. **On macOS, Linux and WSL, Grep and Glob are not tools by default.** TR 304: "On macOS, Linux, and WSL, Claude Code leaves Glob and [Grep](#grep-tool-behavior) out of the default tool set, and Claude searches with `find` and `grep` through the Bash tool instead." The searches "reach your hooks and permission rules as `Bash` calls" (TR 304). Condition: the platform. Windows: "On Windows, it's part of the default tool set." (TR 304). Marked: the guide treats Grep and Glob as tools to select on every platform (C1).
2. **Read does not always load the full file.** TR 516: "By default one call returns at most 25,000 tokens, or the value you set in [`CLAUDE_CODE_FILE_READ_MAX_OUTPUT_TOKENS`](/docs/en/env-vars), and refuses a whole file over 256 KB, so Claude reads a larger file in pages with `offset` and `limit`." A Write after a partial read needs a full read first (TR 676). Condition: the default limits. Claude Code v2.1.296 or later can read a whole file with `allow_large: true` (TR 516). Marked: K3 and S3 say "full file" with no limit (C3).
3. **To find callers, a language server can replace text search.** TR 351: "Find all references to a symbol". Condition: TR 358: "Claude Code keeps the tool inactive until you install a [code intelligence plugin](/docs/en/plugins/code-intelligence) for your language." The guide does not name the LSP tool. S5 uses Grep for the same goal.
