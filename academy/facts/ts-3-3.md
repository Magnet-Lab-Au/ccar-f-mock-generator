## 2. The takeaway

**Proposed heading (9 words):** "A rule with a glob loads only for matching files"

**Short answer:** A file in `.claude/rules/` with a `paths` list of glob patterns loads into context only when Claude works with a file that matches. A glob such as `**/*.test.tsx` finds files by type in every folder, and a CLAUDE.md in one directory cannot do that.

Support: F1 to F4 (the `paths` field and its globs), F5 to F8 (when a rule loads, with conflict C1), F9 to F12 (rules against a directory CLAUDE.md, with C2), F13 (the exam answer).

The real difference is the scope: one folder or a glob across folders (LCB 116, GUIDE 818).
