## 2. The takeaway

**Proposed heading (8 words):** "Few-shot examples fix what instructions alone leave inconsistent"

**Short answer:** When detailed instructions still give inconsistent output, add 2 to 4 targeted examples that show the exact output format and the hard cases, each with the reason for the choice. Varied examples help Claude handle new cases and varied documents, not only the cases that the examples show.

Support: F1 to F3 (C2), F4 to F7 (C1, C3), F8 (C5), F10 and F11 (C4).

The response is still specific and complete.</rationale>
</example>

- **C6. Examples for format against structured outputs.** S2 uses examples for a fixed format (GUIDE 463). The exam uses the guide for 4.2 and teaches the schema under 4.3.
