## 2. The takeaway

**Proposed heading (9 words):** "The coordinator splits the work and routes every result"

**Short answer:** A coordinator agent splits the task, calls only the subagents that the query needs, and is the only path between them. Each subagent starts with a fresh context, so a split that is too narrow leaves gaps that no subagent can see.

Support:
- "splits", "calls only the subagents that the query needs": 1.2-K3 (135), 1.2-S1 (143).
- "the only path between them": 1.2-K1 (133), 1.2-S4 (146).
- "fresh context": 1.2-K2 (134). D: "Each subagent starts with a fresh, isolated context window. It doesn't see your conversation history" (`2026-10-14-claude-code-docs-sub-agents.md` 1066).
- "a split that is too narrow leaves gaps": 1.2-K4 (139). Sample question 7, answer (832): "The subagents executed their assigned tasks correctly—the problem is what they were assigned."

## 9. Conflicts

- **C1. All communication through the hub (K1, S4) against direct messages (D).** Guide 133, 146. Docs: named subagents can message each other (SDK 180, AT 41, SA 1075, 1113). Agent teams: teammates "communicate directly with each other" (AT 13), an experimental feature (AT 10). The exam uses the guide. The docs do not say that hub routing is wrong.
- **C2. One layer (guide) against nesting (D).** The guide does not mention nesting. Claude Code and the Agent SDK nest up to 3 layers by default (SA 1022, SDK 624). Managed Agents: "Delegation is one level deep" (MA 27, 371). The exam uses one hub.
- **C3. Tool name.** Guide: "Task tool" (999, 152). SA 490: "In version 2.1.63, the Task tool was renamed to Agent." SDK 307: "Agent" in `tool_use` blocks, "Task" in the `system:init` list. The exam uses "Task". Mainly a 1.3 conflict. It matters for 1.2 only if the figure labels the spawn arrow.
- **C4. K2 nuance.** The docs agree for a normal subagent. A fork "inherits the parent conversation instead of starting fresh" (SA 1066). The fresh context "isn't empty" (SDK 178): it has its own prompt, CLAUDE.md and tools (SDK 188-190). Forks belong to 1.3-K4 and 1.7.
- **C5. Weak doc support for K4, S2, S3.** Only the guide states them. Near ideas: SA 985, MA 92. Present them as design practice from the guide, not as product behavior.
- **C6. Sample questions 8 and 9** test 5.3 and 2.3 first. Their link to 1.2 is a judgment of this agent. Question 7 is the only clear 1.2 sample.
