## 2. The takeaway

**Proposed heading (10 words):** "Retry with the exact errors, but not for missing facts"

**Short answer:** When an extraction fails a check, send the document, the failed result and the specific errors back, so the model can correct it. A retry fixes format and structure errors, not information that the source does not have, and code must still check the meaning, because a schema stops only syntax errors.

Support: F1 to F3 and F9 (K1, S1), F4 and F5 (K2, S2), F6 to F8 and F10 (K4, S4). K3 and S3 rest on the guide only (C5).
