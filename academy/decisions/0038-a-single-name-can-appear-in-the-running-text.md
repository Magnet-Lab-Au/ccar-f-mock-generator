# 0038: A single name can appear in the running text

- Date: 14 October 2026
- Status: accepted
- Text confirmed by the owner: 14 October 2026, in the discussion (working rule 35)
- Diagram: none
- Names: decision 0032. Its text does not change (working rule 26).

## Question

Decision 0032 says: "Code never appears in the running text. It can appear in any popup: a popup on a diagram, or a preview card." Tab 1 has names such as `allowed_tools`, `updatedToolOutput` and `--fork-session` in its running text. Decision 0032 does not say whether a single name counts as code.

## Options

1. A single name counts as code, so it goes into a popup.
2. A single name can appear in the running text.

## Decision

Option 2. A single name of an API field, a parameter, a command, a flag or a value can appear in the running text, in code font. A line of code, or more than one line, stays in a popup (decision 0032).

## Reason

The exam uses these names, and a candidate must know them. A name in a popup is hidden from a reader who does not open the popup.

## How we decided

The morning report of the night of 14 October 2026 named the question (item 8). The assistant recommended option 2. The owner said: "yes, allow single names".

None.
