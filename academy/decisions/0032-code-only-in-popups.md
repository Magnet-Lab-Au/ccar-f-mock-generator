# 0032: Code only in popups

- Date: 13 October 2026

## Question

Decision 0004 says that code appears "only in a hover popup on a diagram". Decision 0005 says that a preview card can show a few lines of code, and a card opens from a fact in the text. Where can code appear?

## Decision

Code never appears in the running text. It can appear in any popup: a popup on a diagram, or a preview card.

## Reason

The audience wants no code in the text (decision 0004). A popup opens only when the reader asks for it, so code in a preview card keeps the text free of code. The 1.1 samples already work this way.

## How we decided

The independent review of the plan found the conflict. The assistant recommended the rule. The owner accepted it.
