How to read the plan

Each figure gets one claim in one sentence, and one type from the table of the plugin:

TypeThe plugin uses it for
Steppera process that changes over time. It opens on the full picture. The reader goes one step at a time with the arrows. Nothing plays by itself.
Small multiplescases, options or failure modes: the same small drawing once for each case, so only the difference changes
Before / afterone drawing with a toggle, so the reader sees exactly what changes. With no script, both panels show.
Live figurea setting that the reader can try. One control changes the picture.
Close-upa claim that lives in one small part, such as the fields of one record, drawn large
Diagrama still drawing of a structure or a data flow
Bars, waffle, dimension linea number. A dimension line sits on the span that it measures.
Grid, table with chipscards, or a matrix of many rows

"Change" says what happens to the figure:

  • Redraw: the type changes.
  • Add: the figure stays, and a picture for a number is added (the plugin rule "every number gets a picture").
  • Keep: the figure already has the right type. It still gets the checks of decision 0013 and screenshots in both modes.

The facts of each figure stay the same. A redraw changes the form, not the content. Each label still comes from the fact sheet of its part (decision 0011).
