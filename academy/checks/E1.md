## Method

`e1-nav.md` gave the agent the closed view of tab 1: the domain headings and the number and heading of each part. The agent got the 20 point texts without their IDs. For each point, it chose a part from the closed view before it opened anything, then opened the part file and judged if the part explains the point. At most 4 parts for each point. No search tool.
