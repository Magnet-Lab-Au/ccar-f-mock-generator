# B2: the traps of the exam

Two agents played writers of exam questions. For each of the 30 parts of tab 1, an agent named the most tempting wrong answer, from the anti-patterns of the guide and the wrong options of the sample questions. Then it checked if the page warns against it. The agents read only the guide and the page. The choice of the trap is their judgment.

Counts: clearly 13, weakly 3, not warned 2.

Sentences the agent proposes:
- 2.1: "Few-shot examples or a keyword routing layer do not fix a minimal description. Fix the description first."
- 2.2: "Never return a failed call as an empty success: the agent then thinks that nothing exists and does not retry."
- 3.4: "When the task already says that it is large or architectural, plan first. Do not start direct and wait for complexity to appear."
- 3.5: "More or longer prose does not fix mixed results. Concrete examples do."
- 3.6: "Only -p makes Claude Code non-interactive. CLAUDE_HEADLESS and --batch do not exist, and a redirect of stdin is not the fix." (The assistant has not checked the claims about CLAUDE_HEADLESS and --batch in the documentation.)

Another risk: three "Guide only" notes say that the product today goes against the answer of the guide (1.3, the Agent tool runs even when the list does not name it. 2.3, the newest models reject any and a forced tool. 3.2, allowed-tools does not restrict). A candidate who remembers these notes can reject the guide's answer. A line "In the exam, answer as the guide says" would help. B1 found the same risk.

Sentences the agent proposes:
- 4.6: "A larger context window does not fix a review that is uneven across 14 files: the cause is attention dilution, so split the passes. A vote of several full-PR runs hides real bugs that only one run finds."
- 5.4: "A larger context window does not stop degradation in a long exploration. Keep the findings in files and give the verbose search to subagents."
- 5.6: "Do not let a subagent choose between conflicting values, also not by date or by the reputation of the source. It reports both values with their sources and dates, and the coordinator decides."

The same risk as in domains 1 to 3: part 4.3 says that current models reject any and a forced tool, and a popup advises auto with strict tool use. The guide's answer for several schemas and an unknown document type is any (4.3-S2).

## Result of the assistant

No fix. Each item asks for new teaching text, so all go to the list for the owner. The most important item is common to B1, B2 and B4: where a product fact goes against the guide, the page does not say plainly which answer the exam expects.
