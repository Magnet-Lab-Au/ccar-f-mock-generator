# C1: a beginner reads tab 1

One agent played a developer who knows Python and web APIs but has never used the Claude API, Claude Code, the Agent SDK or MCP. It read the top of tab 1, domain 1 and domain 3, in order, and nothing else.

## The main result

- Domain 3: the beginner could mostly study from it. Hardest gaps: slash commands and permissions are not explained.
- Domain 1: no. The page assumes that the reader knows the shape of an API message with tools, what Claude Code and the Agent SDK are, and how built-in tools differ from the tools of your code.
- First addition that the agent asks for: a short primer before domain 1, with one map of the products (what each is, and who runs the tools), one tool definition with one tool_use and tool_result exchange in JSON, and a glossary: tool, built-in tool, hook, session, fork, permission mode, MCP, slash command, CLAUDE.md, skill.
- Second: where the guide and the documentation disagree, one line "For the exam: <the guide's answer>".

Hardest parts: 1.3 (Task tool, allowedTools, AgentDefinition, fork, session and SDK code at once), 1.5 (two kinds of hook with no names, MCP, permission modes) and 3.2 (commands merged into skills, two fields where the guide and the documentation disagree, "context: fork"). Easiest: 3.3, 3.5 and 3.6.
