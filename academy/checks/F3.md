# F3: load time and size of each tab

Script: `tools/measure-load.js`. Each tab loaded 3 times from the local disk, with the median.

| Tab | DOMContentLoaded | load | HTML | of it SVG | Page data JS | HTML + JS, gzip |
|---|---|---|---|---|---|---|
| 1, Exam guide breakdown | 63 ms | 65 ms | 534 KB | 80 KB | 407 KB | 81 KB + 72 KB |
| 2, Behind the mocks | 38 ms | 40 ms | 229 KB | 90 KB | 152 KB | 37 KB + 33 KB |

## Result of the assistant

- Both tabs load fast from disk. Over a network, a server that compresses sends about 153 KB for tab 1 and 70 KB for tab 2. That is small for a page of this length. No fix.
- The largest part is the preview cards of tab 1: 706 cards with 329 KB of the 407 KB of page data. Each card holds an excerpt of its source. The page loads all of them at the start.
- For the move into the portal (decision 0017): the portal can load the cards of a part only when the reader opens that part. This is a design question for that move, not for now.
- Not measured: the time on a slow phone or a slow network. The checks run only in a headless browser on this computer.
