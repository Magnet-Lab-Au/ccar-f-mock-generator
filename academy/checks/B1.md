# B1: answer the mock questions after reading tab 1

## Method

- `tools/extract-text.js` wrote the text of tab 1 as a reader sees it, with all levels, figure labels, step captions, popups and preview cards.
- `tools/make-b1.py` wrote one question file for each domain: scenario story, question, options and the number to select. No point, no task statement, no answer.
- 7 of the 300 questions are left out, because a tab shows them by ID or by option text (`B1-left-out.json`). 293 remain.
- One agent for each domain read only its page file and its question file. Each agent said that it read only these two files.
- For each answer, the agent quoted the page. `tools/score-b1.py` scored each answer against `mocks/mock-NN.answers.json` and checked each quote against the page file.

## What the scores mean

- Each answer is correct, and each has a sentence of the page that supports it. So the page holds the facts that the 293 questions need.
- The score cannot separate the page from what the model already knows. A model that knows the subject can find a supporting sentence for an answer that it chose from its own knowledge. The notes of the agents are the more useful result.
- The 4 answers with basis "own" are the clearest gaps: M4-S30-T1, M4-S51-T1, M5-S04-T1 and M5-S06-T2.
