## The portal

- A React 19 single-page app (Vite, TypeScript, Tailwind 4, React Router) on Cloudflare Pages, with an Express, Prisma and Zod backend on DigitalOcean and Supabase for login and the database.
- A page is a React component in `frontend/src/pages/`, with a route in `frontend/src/App.tsx` and an entry in `frontend/src/layouts/nav.ts`. A gated page uses `SectionRoute` (`RouteGuards.tsx`). `EXTENDING.md` gives the steps.
- Content is files loaded into the database (the mocks are `backend/content/ccar-f/mock-N.v1.json`). No CMS.
- `PLAN.md` lists the exam guide as post-MVP, so no plan exists yet for these pages. The portal's `CLAUDE.md` says no code without an approved plan.

## Three ways to fit the two tabs

| Way | What it is | For | Against |
|---|---|---|---|
| A | Copy the built files into `frontend/public/academy/` | The pages work as they are (the CSP fits). This is the "copy" of decision 0017. | Files in `public/` need no login, against "everything sits behind auth". No portal sidebar. No iframe (DENY). |
| B | A React page that loads the built HTML and starts `academy.js` on it | Keeps the login, the section gate and the sidebar. | `academy.js` needs an `init(root)` start, the page data must be a module or JSON, the CSS must be scoped against Tailwind, and the HTML needs `dangerouslySetInnerHTML`. |
| C | Rewrite the tabs as React and Tailwind, from JSON that the Python build writes | Uses the portal's own parts (dialog, tooltip, theme). | The most work. The portal has no stepper, no figure component and no before/after toggle. |

## What changes in any way

- CSS variables: the pages use `--bg`, `--surface`, `--accent`, the portal `--color-canvas`, `--color-surface`, `--color-ink`.
- Fonts: the portal already has Sora. IBM Plex Mono is missing, and a new package must be flagged first ("Stack discipline").
- Dark mode: the pages keep `academy-theme` and their own button. The portal keeps `theme` and sets `.dark` on `<html>`. One of the two must go.
- About 60 links between the tabs become routes, and React Router does not scroll to a `#hash` by itself.
- About 915 links point to `main` of the public GitHub repository, with line numbers that move when a file changes (A2 found the same for `HANDOFF.md`).
