# 0026: The build guide does not show MCP, subagents, hooks or sessions at work

- Date: 6 October 2026
- Status: accepted
- Diagram: none

## Question

The pipeline uses no MCP, no subagent, no hook and no session. Must the build guide show them at work?

## Options

1. No. The build guide shows only the parts of the exam guide that the pipeline uses.
2. Yes. A step is added or changed so that the pipeline uses them.

## Decision

Option 1. The build guide does not show MCP, subagents, hooks or sessions at work. The pipeline uses none. The build guide gets one short section that says so, and why.

## Reason

No exam guide point gives this reason. The reason is plain. A step that exists only to show a feature makes the program worse. The questions of each mock still cover all five domains.

## How we decided

`HANDOFF.md` listed this as an open item to discuss before the design of the steps. The assistant suggested option 1 for MCP, subagents, hooks and sessions. The owner said: "I accept no MCP and subagents". The assistant asked again for hooks and sessions. The owner said: "Sure". The owner approved a short form of this text, for MCP and subagents. The owner did not confirm the full text.
