# 0060: Across mocks: no copy, and a close repeat is a known limit

- Date: 8 October 2026
- Status: accepted
- Diagram: none. No step changes. Diagram 11 shows rule B9.

## Question

After the rewrites of mock 2, an independent reviewer and the second review found that three new questions are still close to another question, and the second review found a fourth. Rule B9 (decision 0056) let them pass. Does the program need a stricter rule across mocks?

## Options

1. A copy is not allowed. A close repeat is allowed and is recorded as a known limit. Rule B9 does not change.
2. A stricter rule B9 that also fails a close repeat.

## Decision

Option 1.

1. **A copy is not allowed.** A copy is a question of a later mock with the same scene, the same answer and the same wrong options as a question of an earlier mock. Rule B9 fails it in step 4, and the owner sends it back if the check misses it.
2. **A close repeat is allowed.** A close repeat shares the scene or the answer with an earlier question, but it is not a copy. It is recorded as a known limit of its mock, with the two question IDs.
3. **Complete independence of the mocks is not a goal.** The guide has 95 ideas, and 5 mocks have 300 slots (decision 0049), so ideas and some answers come back.
4. Rule B9 does not change.
5. Before the owner marks a later mock, the assistant compares its 60 questions with the questions of the earlier mocks and shows the count of copies and of close repeats.

## Reason

Plain reason: a participant who takes several mocks must not meet the same question again. Meeting the same idea, or the same correct action in a new scene, is practice, not a repeat. The guide tests each idea from several angles, and some ideas have only one correct action (decision 0056).

## How we decided

The owner decided: "across mocks, a copy of an earlier question (same scene, same answer, same wrong options) is not allowed. A close repeat is allowed and is recorded as a known limit. Complete independence is not a goal." The owner also decided: "Do not change rule B9." The owner asked for the comparison before the marking of mock 3.
