- Date: 9 October 2026
- Status: accepted
- Diagram: none. No step changes.

## Question

Mocks 1 to 5 are built and accepted. The git tag marks the commit of this set. The portal already has a version 1 of the mocks. Which version name does the set get?

## Options

1. Version 2, with the tag `mocks-v2`.
2. Version 1, with the tag `mocks-v1`.

## Decision

Option 1. The tag `mocks-v2`, with the message "Mocks 1 to 5 built and accepted", marks commit aca8a23 on GitHub. The first tag `mocks-v1` on the same commit is deleted, on this computer and on GitHub.

## Reason

Plain reason: the portal already has a version 1. The same name for two different sets of mocks confuses the readers of the portal.

## How we decided

The owner asked for the tag `mocks-v1`. Then the owner asked to rename it to `mocks-v2`, because the portal already has a version 1.

The owner has not confirmed the text of this file. No independent reviewer checked this file.
